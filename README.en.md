# dsh-ark-lore

Arknights lore memory for DeepSeek Harness. Faction files, alias routing, an in-world timeline, operator records, community memes, a full story archive, and on-demand PRTS lookup.

## What is inside

- 503 entities, 607 events, 70 community memes
- 423 operator records, 3,658 sections
- 2,326 story segments, 378,860 lines (main story, operator records, events, roguelike endings/IF lines)
- Terra-calendar timeline from 1002 to 1099

## Install

From GitHub:

```sh
dsh plugin add github:shengsheng778/dsh-ark-lore
```

From a release tarball:

```sh
dsh plugin add https://github.com/shengsheng778/dsh-ark-lore/releases/download/v0.11.1/dsh-ark-lore.tgz
```

## Tools

- `ark_find` — find an entity, event, meme, or story by name or fuzzy phrase
- `ark_read` — read a card, operator record, or story; `summary`, `full`, `context`, `records`
- `ark_timeline` — browse events by Terra year, around an event, or by faction
- `ark_web` — search/read PRTS, apply corrections, learn a new meme, or sync new game stories
