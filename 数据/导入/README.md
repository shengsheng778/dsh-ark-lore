# imports

放补丁数据，加载时和自带数据合并。每个文件一个 JSON：

```json
{
  "entities": [ { "id": "...", "type": "city", "name": "...", "...": "..." } ],
  "events": [ { "id": "ev....", "title": "...", "time": { "year": 1097 }, "...": "..." } ]
}
```

也可以直接放一个实体数组。id 不能和自带数据重复，事件里的 `entities` 必须能在实体表里找到。

批量导入脚本建议先写到临时目录，跑 `node 脚本/lint.mjs` 过了再放进这里。
